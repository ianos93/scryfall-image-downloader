Quick Instructions

  • Enter card names (one per line) or upload a .txt decklist file
  • Select image quality and options (Paper Only, First Print)
  • Click "Summon Cards" to fetch from Scryfall
  • Choose an output: Individual Cards (ZIP), Visual Decklist (PNG or PDF, stacked or grid), or Print for Proxy (PDF)
  • Successful fetches are saved to Recent Lists so you can reload them later

Formats Supported

  • Card names: Lightning Bolt
  • With quantities: 4 Lightning Bolt or 4x Lightning Bolt
  • With set codes: Lightning Bolt (M10) or Lightning Bolt M10
  • With collector numbers: Savannah Lions DMR 270 or Lightning Bolt M10 #341
  • Deck sections: Deck, Sideboard, //Sideboard, Commander
  • Repeated lines are added together: 2 Sol Ring twice gives 4 copies
Tip: Use set codes + collector numbers to fetch specific printings (e.g., Sol Ring 6ED 350)

What's New in v4.2

  • Visual Decklist: a Grid layout with quantity badges, any background colour, and PDF as well as PNG downloads
  • Every output tab opens with its controls and download button at the top, kept in view as you scroll
  • A finished run lists any cards that failed or were corrected, and takes you to their line in Card Names
  • Errors appear next to the button that failed instead of in pop-ups, and screen readers hear progress and results

Earlier versions are listed in the README on GitHub.

Cache & Saved Lists

Card metadata is cached in your browser for 7 days to avoid repeat API calls. Each option combination (Paper Only, First Print, Premium) is stored separately. Recent Lists are stored separately again, so clearing the cache never removes them.

Card Database

First Print and Paper Only use a local card database to resolve printings without API calls. Refresh when a new set releases (~every 3 months).
