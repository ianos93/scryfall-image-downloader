Quick Instructions

  • Enter card names (one per line) or upload a .txt decklist file
  • Select image quality and options (Paper Only, First Print)
  • Click "Summon Cards" to fetch from Scryfall
  • Download individual images as ZIP or visual decklist as PNG

Formats Supported

  • Card names: Lightning Bolt
  • With quantities: 4 Lightning Bolt or 4x Lightning Bolt
  • With set codes: Lightning Bolt (M10) or Lightning Bolt M10
  • With collector numbers: Savannah Lions DMR 270 or Lightning Bolt M10 #341
  • Deck sections: Deck, Sideboard, //Sideboard, Commander
Tip: Use set codes + collector numbers to fetch specific printings (e.g., Sol Ring 6ED 350)

What's New in v3.1

  • Memory Management — image caching for fast preview switching and proxy generation
  • Cancel Fetches — abort mid-flight requests without freezing the UI
  • Live Preview — transparent background toggle now instantly updates
  • Cache eviction logic properly removes oldest elements rather than a hard wipe

Cache Management

Card metadata is cached in your browser for 7 days to avoid repeat API calls. Each option combination (Paper Only, First Print, Premium) is stored separately. Clear the cache if you need to force a re-fetch or free up space.

Card Database

First Print and Paper Only use a local card database to resolve printings without API calls. Refresh when a new set releases (~every 3 months).
